Fondos/objetos reemplazables de cinemáticas. `habitacion_304.png` debe medir 960 x 540 px. La Cinemática 1 usa un fondo procedural si ese archivo no está presente.

Los objetos `puerta_habitacion.png`, `ventana_rejas.png` y `cama_hospital.png` se definen en `data/textos.json`, con posición, tamaño de destino y capa. Sus PNG pueden tener fondo transparente.
