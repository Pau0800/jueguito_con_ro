Sprites transparentes reemplazables de personajes de cinemática. Los nombres y tamaños de destino están definidos en `data/textos.json`:

- `periodista_1.png` y `periodista_2.png`: proporción vertical, destino de 48 x 96 px.
- `chica_1_chaleco.png` y `chica_2_chaleco.png`: personajes sentados, destino de 64 x 80 px.

Si falta un archivo se dibuja una silueta pixelada de reserva; para personajes sentados se incluye el chaleco de fuerza en el placeholder.
