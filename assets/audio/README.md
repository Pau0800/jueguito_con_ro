# Audio opcional

Los clips faltantes no detienen el juego; el administrador de audio informa la ruta ausente y continúa en silencio.

## Hospital

- `ambiente/murmullos_hospital.ogg`: loop ambiental estéreo, 44.1 kHz.
- `ambiente/zumbido_fluorescente.ogg`: loop mono o estéreo, 44.1 kHz.
- `ambiente/gotera.ogg`: loop corto, mono, 44.1 kHz.
- `sfx/pasos.wav`: pasos cortos, mono, 22.05 kHz.

## Cementerio

- `ambiente/viento_cementerio.ogg`: loop estéreo, 44.1 kHz.
- `ambiente/grillos.ogg`: loop mono o estéreo, 44.1 kHz.
- `sfx/pasos_tierra.ogg`: paso corto sobre tierra, mono.
- `sfx/salto.wav`: salto corto, mono.
- `sfx/caida_tumba.wav`: caída amortiguada, mono.
- `sfx/rescate.wav`: salida de la tumba, mono.

Los niveles de ambiente y efectos se ajustan en `juego/config.py` (`VOLUMENES_AUDIO`).
